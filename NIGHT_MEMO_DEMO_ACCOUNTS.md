## How conversion works

The user enters a short Account ID and matching password on the Night Memo login page. The test-only login adapter maps the Account ID to an internal email address and maps the short password to the longer Supabase Auth password.

**Example — C10:**

| Field | Value |
| --- | --- |
| User-entered account | `C10` |
| User-entered password | `c10` |
| Supabase Auth email | `c10@accounts.nightmemo.example.com` |
| Expected Supabase Auth password | `NM-DEMO-c10-Aa1!` |

For the demo accounts above, the expected email is the lowercase Account ID followed by `@accounts.nightmemo.example.com`.

## Verify which accounts actually exist

Run the following **read-only** SQL in your test Supabase project's SQL Editor. It reports real account presence and the *expected* converted password; it does **not** reveal or verify the currently stored password.

```sql
select
    ua.login_id as account,
    ua.role,
    ua.active,
    au.email as supabase_email,
    lower(ua.login_id) as password_to_enter,
    'NM-DEMO-' || lower(ua.login_id) || '-Aa1!' as expected_internal_password,
    (au.id is not null) as auth_user_exists,
    (au.email_confirmed_at is not null) as email_confirmed
from public.user_access ua
left join auth.users au on au.id = ua.auth_user_id
order by ua.login_id;
```

## If a demo account cannot log in

1. Verify that its Supabase Auth record exists and is enabled.
2. Confirm the website is connected to the same Supabase project used to create accounts.
3. Confirm that the **test-only** short-password conversion is enabled in the deployed website.
4. If an existing account was originally created with a random password, reset its password through the protected Maintenance account-management function or a trusted Supabase Admin API script; changing the conversion setting alone does not reset stored passwords.

**Never** publish real user passwords, Supabase secret/service-role keys, or exported private credential files to GitHub. Remove this reference and disable predictable test-password conversion before any real clinical deployment.
